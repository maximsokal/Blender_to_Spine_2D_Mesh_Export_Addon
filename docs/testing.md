# Testing and Release Validation

## Current release candidate

The current extension candidate is **0.81.0**.

Supported product scope:

- Blender 5.2.0 or newer.
- Single-object and standalone multi-object export for Spine 3.8.99, 4.0.64, 4.1.24, 4.2.43, and 4.3.23 according to the target/profile capability matrix.
- Connected and mixed composition for Spine 4.2.43 only.
- Three explicit texture modes: Normal - UV Segments, Camera Projection, and Depth Camera Projection.
- Scene settings schema 7.
- Public selected-object export remains standalone-only.

A focused run is not a release gate. Every required validation layer must pass on one exact commit, and every runtime claim must use JSON and textures generated by that commit.

## Manual Spine validation

Import representative fresh outputs into the exact selected Spine Editor version.

For Spine 3.8 and 4.0, confirm legacy attachment swaps, frame order, Loop wrap, texture paths, and generated controls.

For Spine 4.1, 4.2, and 4.3, confirm native sequence metadata, sequence ownership, texture paths, weighted attachment topology, and generated controls.

For Depth Camera Projection, move X/Y/Scale controls and confirm that the generated relief remains coherent, the farthest visible point stays at the zero relief plane, and no retained point deforms away from the camera.

## Release evidence

A release claim records:

- exact commit SHA and clean working tree;
- Python and Blender versions;
- complete pytest summary;
- both Depth Camera Projection Blender markers;
- all four historical sequence matrix markers;
- real-bpy summary;
- archive path, size, and SHA256;
- Blender extension validation result;
- isolated install result;
- manual Spine validation notes.
