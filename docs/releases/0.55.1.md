# 0.55.1

## Blender headless acceptance correction

The Object Origin production pivot code from `0.55.0` is unchanged.

The Blender 5.2 headless acceptance worker previously captured `matrix_world`
immediately after assigning `Object.location`, before Blender had evaluated the pending
transform update. Production preparation requests the dependency graph, which caused
Blender to materialize the authored translation. The worker incorrectly reported that
normal dependency-graph evaluation as a source-object mutation.

The corrected worker now:

- activates the fixture object;
- calls `view_layer.update()` before capturing its baseline;
- verifies source vertex coordinates and authored transform channels exactly;
- compares evaluated `matrix_world` values with an absolute tolerance of `1e-7`;
- reports the maximum matrix delta;
- applies the same immutability checks to every standalone object.

This correction changes only test synchronization and diagnostics. Camera Projection,
connected composition, Spine codecs, constraint schedules, and production pivot behavior
are unchanged.
