# 0.55.15

## Connected and mixed projection normalization

Slice 5 applies the approved Normal / UV Segments projection contract to connected and mixed internal composition without exposing those modes in the public UI.

### Added

- `A1ProjectedObjectAnalysis`, an immutable per-object record containing the shared projection direction, projected Object Origin, nearest and farthest evaluated vertex depths, nearest projected vertex position, projected bounds, source input index, prefix, component ID, and owned slot names.
- Blender 5.2 headless acceptance for all six signed axes in connected and mixed composition.
- Blender 5.2 headless acceptance for Perspective and Orthographic Active Camera connected and mixed composition.

### Changed

- Connected Normal / UV Segments preparation now accepts `ACTIVE_CAMERA` and removes absolute per-object main translation before hierarchy composition, exactly like signed-axis connected preparation.
- The connected global `<group>_main` is placed at the selected anchor's absolute projected Object Origin.
- Connected object mains remain anchor-relative, so their final setup world positions equal the corresponding standalone projected positions.
- Connected depth layers remain grouped by projected Object Origin depth.
- Connected setup slots are ordered as complete object blocks from far to near by each object's nearest evaluated vertex depth.
- Mixed composition performs one final slot-only object-block pass across connected and standalone subgroup boundaries, allowing deterministic nearest-vertex interleaving while preserving subgroup bones, skins, constraints, attachments, and animation metadata.

### Preserved

- Slot order inside each object block is unchanged.
- Source input order remains the tie-break inside `z_tolerance` clusters, followed by component ID.
- Existing rendered Camera Projection, grouped camera overlay, crop/contour flattening, public standalone-only UI routing, Spine codecs, UV topology, texture baking, and source Blender state are unchanged.
- Spine 4.1 connected and mixed capability restrictions remain fail-closed.
