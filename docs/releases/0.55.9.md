# 0.55.9

## Active Camera depth-compensation fixture index correction

The 0.55.8 focused validation exposed a second fixture defect in the pure setup-pose test. The fixture constructed valid `LegacyZGroup` values but still assigned attachment vertices to hardcoded group indices `(0, 1, 2)`.

Production A1 Z-group assignment and the selected rig profile both use the profile-owned `z_index_base`, which is currently `1`. Therefore valid production bindings for the three fixture groups are `(1, 2, 3)`, and the production compensation helper correctly rejected the nonexistent group `0`.

### Fixed

- The pure Active Camera setup-depth fixture now reads group indices from `rig.info.z_groups` instead of assuming a zero-based index.
- The zero-depth assertion resolves the group by `z_value == 0.0` instead of a hardcoded numeric index.
- The fail-closed unknown-group case derives an invalid index from the actual profile-owned range.

### Unchanged

- Production Active Camera projection, camera-frame evaluation, geometry projection, depth-parent compensation, standalone draw order and Blender acceptance worker are unchanged.
- Signed-axis projection, existing rendered Camera Projection, connected and mixed assembly, Spine codecs, UV topology and texture baking are unchanged.
