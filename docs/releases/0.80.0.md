# 0.80.0

## Release scope

Version 0.80.0 promotes the Blender 5.2 Rewrite exporter after completing real Blender sequence acceptance across every supported Spine target and every production composition scope.

## Sequence baking

- Normal - UV Segments sequence baking evaluates animated source transforms and camera-dependent surface inputs on the temporary UV bake target for every timeline frame.
- Texture Coordinate `Camera` and `Reflection` inputs are supported by the audited Cycles object-bake route without changing exported UV-segment topology.
- Camera Projection retains its separate render, crop, contour, and projection-attachment pipeline.
- Source object transforms, current frame, active object, selection, materials, Scene bake settings, render settings, Camera state, and temporary Blender datablocks are restored after export.

## Real Blender acceptance

The release gate includes real Blender 5.2 end-to-end sequence exports at 128x128 with two frames and one Cycles sample.

Standalone multi-object coverage:

- Spine 3.8, 4.0, 4.1, 4.2, and 4.3;
- Normal - UV Segments and Camera Projection;
- two animated objects per case;
- legacy attachment-swap serialization for Spine 3.8 and 4.0;
- native sequence serialization for Spine 4.1, 4.2, and 4.3.

Connected and mixed coverage:

- Spine 4.2, the only production target that supports these composition scopes;
- Three-Axis Rotation and Two-Axis Rotation + Scale profiles;
- Normal - UV Segments and Camera Projection;
- two-object connected output;
- mixed output containing a two-object connected subgroup and one standalone object;
- native Loop sequence timelines for every exported object;
- connected wrapper hierarchy and mixed standalone hierarchy isolation.

## Version and packaging

- The extension manifest version is `0.80.0`.
- The expected package name is `blender_to_spine2d_mesh_exporter-0.80.0.zip`.
- Blender 5.2.0 remains the minimum supported Blender version.
- Scene settings schema remains version 6.

## Preserved boundaries

- Public selected-object export remains standalone-only.
- Connected and mixed services remain explicit development/API composition routes.
- Unsupported target, profile, and composition combinations remain fail-closed before Blender geometry or bake work.
- Historical 0.55 release notes and contracts remain preserved as implementation checkpoints.
