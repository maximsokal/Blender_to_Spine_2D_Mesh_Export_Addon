# 0.55.2

## Normal / UV Segments signed-axis projection foundation

This release implements the first behavior-changing projection slice from the approved
`normal_uv_segments_projection_space_and_draw_order.md` plan.

The single-object Normal / UV Segments preparation pipeline now accepts six signed-axis
projection directions:

- `POSITIVE_X`;
- `NEGATIVE_X`;
- `POSITIVE_Y`;
- `NEGATIVE_Y`;
- `POSITIVE_Z`;
- `NEGATIVE_Z`.

After Blender rotation, scale, mirror, and shear are normalized into immutable geometry,
the complete Mesh snapshot and Blender Object Origin are transformed into the canonical
`U/V/D` frame before depth groups, segmentation, and rig planning.

`POSITIVE_Z` remains the exact compatibility path used by existing scenes and returns the
same normalized snapshot without an additional geometry replacement.

Normals and face normals use the same right-handed orthonormal basis as vertex positions.
Topology, winding, UV data, source lineage, and the source Blender object are unchanged.

`Active Camera` remains intentionally unavailable in this slice. Requests carrying
`ACTIVE_CAMERA` fail closed until the evaluated camera projection frame is implemented in
the later camera slice.

The public UI does not expose the projection dropdown yet. UI registration and migration
remain a later documented slice.
