# 0.55.6

## Standalone Normal / UV Segments object-block draw order

This release implements Slice 3 of the approved
`normal_uv_segments_projection_space_and_draw_order.md` plan.

Standalone Normal - UV Segments composition now measures every prepared object's
world-space projected depth from the complete immutable source geometry:

- projected Object Origin depth comes from `source_snapshot.world_matrix[11]`;
- each local projected vertex depth comes from `vertex.position[2]`;
- nearest world depth is the maximum of origin depth plus local vertex depth;
- farthest world depth is the corresponding minimum;
- stable `VertexId` values are retained for deterministic diagnostics.

The final Spine setup slot order is emitted from far to near using each object's nearest
projected vertex. All slots owned by one object remain one contiguous block, and the
internal segment-slot order of that object is unchanged.

Depth values within the configured multi-object `z_tolerance` retain source input order,
with `component_id` as the final deterministic fallback. Tolerance clustering uses one
stable cluster anchor and does not chain-merge indirectly adjacent depths.

Composition continues to build bones, constraints, skins, weighted attachments, bone-index
maps, and animation namespaces in source component order. Only the final setup `slots`
tuple is replaced. Existing non-empty draw-order animation timelines fail closed because
their relative offsets require a separate explicit rebasing implementation.

The Blender 5.2 headless acceptance creates three real cuboids whose Object Origins do not
predict their nearest geometry depth. It verifies all six signed-axis directions, complete
object slot blocks, preserved internal segment order, projected pivots, and unchanged source
objects.

Camera Projection setup ordering is unchanged. Connected and mixed composition remain
unchanged and development-only until their dedicated normalization slice. The public
projection-direction dropdown is not registered yet, so existing scenes continue to use
`+Z` by default.
