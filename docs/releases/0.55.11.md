# 0.55.11

## Markdown-aware semantic release-contract correction

The 0.55.10 focused validation exposed that semantic prose normalization removed casing, whitespace and hyphenation, but retained Markdown backtick delimiters around inline code identifiers.

As a result, the documented phrase `profile-owned z_index_base` normalized to `profile owned `z_index_base`` rather than `profile owned z_index_base`, even though the release note contained the required meaning.

### Fixed

- Semantic prose normalization now removes Markdown backtick delimiters before comparing release-note text.
- Inline code identifiers such as `z_index_base`, `LegacyZGroup` and `projection_direction` are compared by their semantic text rather than Markdown presentation.
- The 0.55.9 profile-owned Z-group release contract now accepts the existing correctly documented wording without weakening its required behavioral claims.

### Unchanged

- Production code, Active Camera projection, depth-parent compensation, rig assembly, standalone draw order and Blender workers are unchanged.
- The corrected 0.55.9 fixture is unchanged.
- Signed-axis projection, existing rendered Camera Projection, connected and mixed assembly, Spine codecs, UV topology and texture baking are unchanged.
