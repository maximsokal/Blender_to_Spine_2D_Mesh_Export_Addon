# 0.55.4

## Projection acceptance release-contract correction

The production signed-axis projection and the Blender headless acceptance worker from
`0.55.3` are unchanged.

The release-contract test for `0.55.3` incorrectly required the exact contiguous phrase
`production axis projection`. The release note correctly described the implementation as
`signed-axis production projection`, so the documentation test failed even though the
release note, production code, and Blender acceptance behavior were valid.

The corrected contract now:

- normalizes case and whitespace before checking prose;
- verifies that the `0.55.3` note states the production projection is unchanged;
- retains checks for the `mathutils.Matrix @ Vector` cause and the observed
  `2.38418579e-7` numeric difference;
- avoids depending on one accidental ordering of equivalent words.

This release changes release-contract validation and version metadata only. Geometry
projection, Object Origin placement, depth groups, UV processing, Spine rigs, Camera
Projection, standalone composition, connected composition, and Spine codecs are
unchanged.
