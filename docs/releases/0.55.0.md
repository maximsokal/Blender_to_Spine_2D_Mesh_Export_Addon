# 0.55.0

## Object Origin pivot for Normal / UV Segments

- Public `TWO_AXIS_ROTATION_SCALE` object-bake export now uses Blender Object Origin as each object's Spine `<prefix>_main` pivot.
- Local Blender Z=0 is the per-object depth reference.
- Z-group bones preserve negative and positive offsets instead of always starting at the minimum Z layer.
- Single-object and public standalone multi-object exports use the same per-object pivot contract.
- Single Normal / UV Segments export preserves `<prefix>_main` placement instead of moving it into the internal base bone.
- Camera Projection retains its previous compatibility placement and minimum-Z policy.
- `THREE_AXIS_ROTATION` remains available to internal code and tests but is hidden from the public Blender UI until separately implemented and validated.

## Spine 3.8

The previously validated Spine 3.8 two-axis constraint order remains unchanged:

```text
Scale Position -> Rotation X -> IK -> Depth -> Rotation Y -> Scale
```

## Unchanged areas

- Connected and mixed composition remain developer-only and are not modified by this release.
- Spine target codecs and target-specific constraint schedules are unchanged.
- UVs, triangles, hull, edges, attachment names, texture paths, source lineage, and slot draw order are not intentionally changed.
