# 0.55.18

## Public Normal - UV Segments projection direction

Slice 6 exposes the already validated signed-axis and Active Camera object-bake routes through the production Blender UI.

### Added

- Persisted `Scene.spine2d_projection_direction` with the exact stable identifiers `POSITIVE_X`, `NEGATIVE_X`, `POSITIVE_Y`, `NEGATIVE_Y`, `POSITIVE_Z`, `NEGATIVE_Z`, and `ACTIVE_CAMERA`.
- A public **Projection direction** selector inside the **Normal - UV Segments** Rig foldout.
- Immutable Scene-profile capture and typed `A1SingleObjectExportSettings.projection_direction` routing for active-object and standalone selected-object plans.
- Blender 5.2 headless acceptance for all seven identifiers, Reset behavior, public standalone-only selected planning, and cross-process `.blend` persistence.

### Behavior

- New and older scenes without a stored value use `POSITIVE_Z`.
- Reset restores `POSITIVE_Z`.
- `ACTIVE_CAMERA` uses the existing object-bake Perspective/Orthographic camera projection with export texture dimensions while preserving UV-segment meshes.
- The existing rendered **Camera Projection** mode remains isolated from the object-bake direction selector and continues to use its render, crop, contour, and flattening pipeline.
- Public selected-object export remains standalone-only. Connected and mixed composition remain development-only internal routes.
- The Scene settings schema remains version 6 because no existing stored value requires transformation.

### Unchanged

- Signed-axis and Active Camera projection mathematics, planarity tolerances, Object Origin placement, depth assignment, rigs, attachments, standalone draw order, Slice 5 connected/mixed normalization, Spine codecs, UV topology, and texture baking are unchanged.
