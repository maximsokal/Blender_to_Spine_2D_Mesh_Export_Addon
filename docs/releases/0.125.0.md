# Release 0.125.0

Version 0.125.0 improves Normal / UV Segments material handling and makes ignored Blender modifiers visible before export.

## Fixed

- Muted shader nodes that were fully traversed conservatively no longer become false `GRAPH_ANALYSIS_INCOMPLETE` blockers.
- View-dependent `BSDF_GLOSSY` materials can use the existing Cycles `COMBINED` object-bake route while preserving Normal / UV Segments topology.
- The real `coin_star.blend` asset now exports through `NORMAL_UV_SEGMENTS -> ORIGINAL geometry -> OBJECT_BAKE -> COMBINED` and produces a non-empty PNG plus Spine JSON.

## Added

- The Analysis foldout now shows an alert when active Blender modifiers are ignored by the Normal / UV Segments source-geometry route.
- Alerts list the affected object, modifier name, modifier type, and whether the modifier is enabled for viewport and/or render.
- Modifiers disabled for both viewport and render are omitted from the alert.
- Multi-object requests group modifier warnings by object without changing export order.

## Compatibility

- Normal / UV Segments continues to export the original Mesh datablock. Applying or converting topology-changing modifiers before export is required when their generated geometry must appear in Spine.
- Camera Projection and Depth Camera Projection behavior is unchanged.
- Minimum Blender version remains 5.2.0.
- Scene settings schema remains 8.
- Expected archive: `blender_to_spine2d_mesh_exporter-0.125.0.zip`.
